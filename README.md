# Super Vibe Mario

A replication of the original **Super Mario Bros** game, generated from LLM models.

Each subfolder contains a version of the game generated by a different LLM model. Open any HTML file in a browser to play.

## Structure

```
super-vibe-mario/
├── dsv4flash-0731/
│   ├── index.html
│   └── _bundle.js
├── glm5.2/
│   └── index.html
├── kat-coder-2.5/
│   └── super-mario.html
├── qwen3.8/
│   ├── platformer.html
│   └── *.png
└── README.md
```

## Prompt Used

> create me a super mario game, the game should look exactly like the original game, follow the mechanics, physics, sprite and all of it
